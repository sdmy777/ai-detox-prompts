# Contributing

Contributions are welcome.

## Good Contributions

- New prompts for rewriting Japanese text
- Before/after examples
- Prompt variants for essays, notes, SNS posts, emails, or documentation
- Reports of phrases that still feel too AI-generated

## Guidelines

- Do not include private, confidential, or copyrighted text without permission.
- Keep the original meaning clear in before/after examples.
- Prefer practical examples over abstract explanation.
- For prompt changes, explain what kind of output changed.

## Pull Request Checklist

- The prompt can be copied and used as-is.
- Examples do not include private information.
- The README stays easy to understand for non-engineers.
